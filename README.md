# 🧭 Department Management Frontend (Next.js 14)

This is the frontend for the Department Management System built with **Next.js 14**, **React 19**, and **Tailwind CSS**. It connects to a GraphQL backend and supports JWT authentication, department management, and pagination.

---

## 🌐 Live Site

🔗 [https://department-management.netlify.app](https://department-management.netlify.app)

---

## 🚀 Getting Started Locally

### 🛠 Prerequisites

Make sure you have **Node.js** (v18 or later) and **pnpm**, **npm**, or **yarn** installed globally.

### 📦 Clone the Repository

```bash
git clone https://github.com/evidence-codes/nextjs-graphql-departments.git
cd nextjs-graphql-departments
```

---

## 📁 Environment Setup

Create a `.env.local` file in the root directory with:

```env
NEXT_PUBLIC_API_URL=https://fullstack-assignment-ijo0.onrender.com/graphql
```

> If running the backend locally, use:
>
> ```env
> NEXT_PUBLIC_API_URL=http://localhost:3000/graphql
> ```

---

## 📦 Install Dependencies

Choose your preferred package manager:

### Using **pnpm** (Recommended)

```bash
pnpm install
```

### Using **npm**

```bash
npm install
```

### Using **yarn**

```bash
yarn
```

---

## 💻 Run the App in Development Mode

### pnpm

```bash
pnpm dev
```

### npm

```bash
npm run dev
```

### yarn

```bash
yarn dev
```

Visit [http://localhost:3000](http://localhost:3000) to view it in your browser.
